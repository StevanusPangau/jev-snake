Strategist ⇄ Executor Architecture

System Design & Latency Decoupling
🧠

Strategist: TypeSafe Jev (~2.6s cadence)

A System One model running on TypeSafe's Choice API. Evaluates the global board state and player coaching instructions, picking between strategic waypoints (food, open_area, border_loop) with calibrated probabilities.

⚡

Executor: Deterministic Local Code (160ms tick)

Runs tick-by-tick in the browser canvas. Executes greedy pathfinding toward the active waypoint, strictly guarded by a BFS flood-fill seatbelt that automatically vetoes moves into trapped pockets with <8 free cells.

🛡️

Lag Immunity & Real-Time Decoupling

Waypoints remain valid across many ticks. Because the model chooses targets rather than raw directional inputs, API latency (~40ms to ~800ms) can never freeze the snake or cause a collision.

💰

Token Economics

At $0.042 / 1M input tokens and free output tokens, each decision costs ~$0.00003. An entire 300-tick game uses only ~$0.0005, making real-time model integration exceptionally cost-effective.
